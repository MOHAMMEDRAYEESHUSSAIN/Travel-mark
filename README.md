## 🌟 Overview

**Travel Mark** is an independent, community-driven travel discovery and experience-sharing platform designed to celebrate the authentic soul of India. The platform helps travelers discover India's best destinations, regional food and cuisines, sacred sanctuaries across traditions, and adventure parks through verified community journeys.

---

## ✨ Features

- **Cinematic Homepage**: Full-width destination slider, live search with multi-category autocomplete (Destinations, Foods, Sacred Sites), and 5 horizontal featured cards.
- **Explore India Filter Hub**: Filter across historical monuments, forts, beaches, hill stations, wildlife sanctuaries, and sacred traditions with a synchronized Leaflet interactive map.
- **Destination Detail Pages**: 25 essential sections including historical background, entry tickets, transport directions, weather, iconic eateries, nearby sacred sites, and an interactive *"What should I visit here?"* interest selector.
- **Community Feed & 8-Step Story Wizard**: Authentic traveler journals featuring multi-photo posts, real personal spending breakdowns, tips, hidden gems, things to avoid, comments, and likes.
- **Personalized Travel Planner**: Interactive day-by-day itinerary generator (morning, afternoon, evening activities) with realistic budget breakdowns (stay, food, transport, tickets) and saving to profile.
- **Travel Photography Gallery**: Masonry grid with category filtering, full-screen lightbox viewer with keyboard navigation (`ArrowLeft` / `ArrowRight`), and photo upload.
- **Dedicated Portals**:
  - *Food & Cuisine*: Regional specialties, street foods, iconic eateries, and dietary filters.
  - *Sacred Places*: Multi-faith pilgrimage circuits (Hinduism, Islam, Christianity, Sikhism, Buddhism, Jainism) with visitor etiquette and dress codes.
  - *Adventures & Amusement*: Theme parks, water parks, river rafting, scuba diving, and wildlife safaris.
  - *Smart Advisor*: "What should I visit?" discovery assistant with clear justifications.
- **User Dashboard & Admin Moderation**: Explorer profile with wishlist, saved travel plans, and an Admin dashboard with moderation queue.

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/MOHAMMEDRAYEESHUSSAIN/Travel-mark.git
   cd Travel-mark
   ```
2. Start any local static web server:
   ```bash
   # Using Python
   python -m http.server 8000
   ```
3. Open your browser and navigate to `http://localhost:8000`.
